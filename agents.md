# Instrucciones del proyecto: Porfolio de Caty

## Objetivo
Crear una web estática de porfolio personal para Caty, estudiante de diseño gráfico.

## Referencia
Utilizar las capturas guardadas en la carpeta JPG_Portfoliokyne como referencia visual de la web https://kynejang.com/.

## Flujo de trabajo
1. Inspeccionar las imágenes de referencia antes de programar.
2. Recrear el diseño inicial usando un único archivo index.html y Tailwind CSS mediante CDN.
3. Crear una página responsive que funcione en ordenador y móvil.
4. Capturar la página renderizada y compararla con la referencia.
5. Corregir diferencias de espaciado, tipografía, colores, alineación, imágenes y tamaños.
6. Realizar al menos dos rondas de comparación y corrección.
7. Personalizar el resultado para que tenga una identidad visual propia.

## Identidad del porfolio
- Nombre: Caty.
- Áreas: diseño gráfico, redes sociales y contenido digital.
- Estilo: editorial, limpio y con personalidad.
- Objetivo: presentar proyectos creativos y facilitar el contacto profesional.

## Reglas
- No modificar las capturas originales.
- No inventar resultados de pruebas o comparaciones.
- No añadir elementos durante la recreación inicial que no aparezcan en la referencia.
- No copiar textos o imágenes protegidas de la web original.
- Utilizar contenido propio o recursos autorizados al personalizar el porfolio.

## Entrega
Respetar la estructura de archivos solicitada por el profesor:
- reference.jpg
- agents.md
- index.html
- styles.css
- README.md

Documentar el proyecto y las instrucciones de visualización en README.md.
